# Contributing

1. Open an issue first (a page to write, a fix, a translation).
2. Branch, change, open a pull request that references the issue.
3. Everything in the repo is in English, except the Persian content and
   Persian UI strings.
4. Content rules: cite sources, date current-affairs claims, separate fact
   from opinion, describe positions as their holders would. Never invent a
   fact, quote or statistic. Persian pages are written in natural Persian,
   not word for word.
5. By contributing you agree your code is MIT and your text is CC BY-SA 4.0.
